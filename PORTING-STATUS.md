| pi-codemode: types, identifier, source (options line + Lark grammar), declarations (`render_declarations`, `render_tool_signature/sample/output_type`, `schema_to_type` with JS-identical number/JSON formatting), `portable` entry, runtime protocol, prelude (`prelude.js`, lockdown, tools/globals/namespaces, `ALL_TOOLS`, close-match errors, console/text/image/exit, store/load, output limits), VM, host execution (calls, deadline, abort, store writes, bridge validation, deterministic `start()`/`deliver`), thread launcher (`acquire_worker`, `on_worker_started`), remote (`serve_codemode_remote`, `CodemodeRemoteServer`, client launcher); TS tests ported: sandbox (thread + JSON-wire remote backends), deterministic, portable, declarations, source, worker-lifetime (admission, exit accounting) | done. Notes: the VM is Boa 0.22 (the engine under pi-jsrt) used directly on a dedicated thread per execution, not a `pi_jsrt::JsRuntime`: a JsRuntime takes ~160 ms (debug) / ~40 ms (release) to start, installs web globals (timers, fetch, crypto...) a sandbox must not have, and cannot be interrupted between promise jobs. VM start is ~25 ms release / ~400 ms debug (the prelude lockdown dominates). Boa cannot be interrupted from outside and discards uncatchable errors raised in an async function resumed after an await, so the script's loops are instrumented with oxc (a tick call at the start of each loop body, no added line breaks); columns on lines with loops shift in stack traces; the tick polls the interrupt flag (deadline, abort, close, already-settled) and counts `interrupt_budget` (loop iterations + promise jobs; the TS `interruptBudget`, message "Execution exceeded its interrupt budget of N", default none for `CodemodeSandbox::new`, 10M for the remote server). Code from `eval`/`Function` is not instrumented and is bounded by Boa's per-call `loop_iteration_limit` (default 100M); a long native built-in cannot be stopped and its thread is abandoned (never joined). Deep recursion hits Boa's recursion limit (4096), which the script cannot catch: the script ends with `RangeError: Maximum call stack size exceeded` (after an await the engine discards it and the script is reported as waiting on a promise that can never settle). `memory_limit_bytes`: Boa has no heap limit; it only caps `ArrayBuffer` allocations (and is part of the fingerprint). Deterministic mode: virtual `Date` clock via Boa's `Clock`, UTC via host hooks, `Math.random` from a seeded mulberry32 (pinned values differ from QuickJS), no `WeakRef`/`FinalizationRegistry`/`Temporal`; fingerprint `boa 0.22, prelude <fnv1a>, deterministic 1, stack <recursion limit>, heap <bytes|none>, budget <n|none>`. Host timezone in `execute()` comes from libc `localtime_r` (honors `TZ`). Engine messages differ (Boa: "cyclic object value", parser messages; a syntax error's stack frame is built from "line L, col C"). `performance.now()` is provided as in QuickJS. Rust API: `CodemodeSandbox` is the base class (`new` = thread sandbox, `remote`, `with_launcher`; `RemoteCodemodeSandbox`/`CodemodeSandboxBase` are aliases); `execute()` fails only when closed and dropping its future aborts the execution; tools are `CodemodeTool::new(name, \|args: Option<Value>, ctx\| async { Ok(Some(value)) })` (`None` = undefined, `Err(message)` rejects); `AbortSignal`/`AbortController` wrap `CancellationToken` with a reason; `start()`'s `on_call` receives a `CodemodeRunHandle` to answer with; remote exchanges return `Result<reply, transport error>`. Not ported: `InlineCodemodeSandbox` (VM on the calling thread; the thread sandbox with `interrupt_budget` covers it), Node worker specifics (`workerUrl`, `wasm`/`loadQuickJSWasm`, `--watch` message filtering), the Cloudflare entry (`cloudflare.ts` Durable Object, `createInlineCodemodeSandbox`, `cloudflare-modules.d.ts`, `wasm.ts`); `serve_codemode_remote`/`CodemodeRemoteServer` are the transport-neutral remote end. TS tests not ported: Node/Bun process-exit, worker constructor and wasm loading failures, "answer cannot be serialized" (Rust values always serialize) |
