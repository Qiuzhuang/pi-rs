Boa cannot be interrupted from outside and discards uncatchable errors raised in an async function resumed after an await, so the script's loops are instrumented with oxc (a tick call at the start of each loop body, no added line breaks); columns on lines with loops shift in stack traces; the tick polls the interrupt flag (deadline, abort, close, already-settled) and counts `interrupt_budget` (loop iterations + promise jobs; the TS `interruptBudget`, message "Execution exceeded its interrupt budget of N", default none for `CodemodeSandbox::new`, 10M for the remote server). Code from `eval`/`Function` is not instrumented and is bounded by Boa's per-call `loop_iteration_limit` (default 100M); a long native built-in cannot be stopped and its thread is abandoned (never joined). Deep recursion hits Boa's recursion limit (4096), which the script cannot catch: the script ends with `RangeError: Maximum call stack size exceeded` (after an await the engine discards it and the script is reported as waiting on a promise that can never settle). `memory_limit_bytes`: Boa has no heap limit; it only caps `ArrayBuffer` allocations (and is part of the fingerprint).
